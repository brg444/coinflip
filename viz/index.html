The picture is the regtest smoke test, pnpm smoke:regtest. The oracle service issues one identity unit and deploys the beacon. The ark client funds two intents and the desk. The desk finalizes one covered call, the writer cancels the other, and the oracle publishes the strike. Settlement then pays the writer the collateral minus the 1,000-sat read fee. A solid green border is a gain, a dashed red border the matching loss, and party colour is the owner. Prices other than the strike are the same formula and were not run.

The regtest smoke test

pnpm smoke:regtest starts arkade-regtest, then the oracle service in this repo. The seeded ark client sends 10,000 sats to the oracle wallet. POST /api/issue mints one unit on that coin. POST /api/deploy pays 330 of it into the beacon. The same client then sends 50,000 to the fill intent, 50,000 to the cancel intent, and 1,000 to the desk. fillQuote finalizes the first. After the cancel deadline, cancel refunds the second. POST /api/samples stores the strike, and POST /api/publish writes that price once the clock has passed expiry + 60. settleQuote spends the vault and the beacon. Transaction ids change every run. Intent fees on this node are 0.0, so none of these pictures include a protocol fare.

7. The beacon can move without touching open vaults

migrate pays the identity unit to a new 32-byte program, for example one with other oracle keys. Three of the five oracle keys and the oracle service sign the migrate digest. Neither side can move the unit alone. Nothing limits the next program, so together they could move it anywhere, and vaults would read whatever it writes. The digest includes the round, so a signature is good for one state. The state packet is copied. Vaults commit to the asset id, not to the beacon script, so they keep reading after the move.

An attest changes the slots. A key that falls off the eight slots can be attested again with the same oracle signatures. The oracle service signs the new packet. Until then the vault has no fixing.

Enforced

  • The premium output exists before the vault output. Finalize will not pay the vault without paying the writer at least the premium.
  • Settle pays from one slot whose key equals the expiry, newest first, using the integer formula above, and folds a leg of 330 sats or less.
  • Settle sees that price only by spending the identity unit. The beacon’s read leaf carries the packet unchanged and adds readFee, 1,000 sats, on output 0. The vault pays it.
  • Attest stores the signed price. The sample is sha256(ctrlTxid || BTCUSD || expiry || price || time). At least threshold of the oracle keys must sign. The smoke test uses one key. The sample time is inside [expiry, expiry + expiryLag], and checkTime(expiry + expiryLag) has passed.
  • Attest moves the round by one, refuses a key already in a slot, and continues the same script and the same unit.
  • Migrate needs three of the five oracle keys and the oracle service key, and continues the unit and the packet onto the signed next program. The vault’s constructor does not contain the beacon script or the committee keys.
  • Cancel after the deadline returns the intent coin to the writer program. Unilateral leaves wait 2,048 seconds.
  • arkd, not a script: no second unit can be minted, because the issue named no control asset. A burn is not blocked: the beacon’s own leaves cannot burn the unit, but a program reached through migrate could, and every vault would then have no fixing.
